# AH LCG — Livrets de règles officiels FFG (liens PDF)

Référence pour le projet rooms playingcards.io. Source : page produit FFG, section **Support**
(https://www.fantasyflightgames.com/en/products/arkham-horror-the-card-game/).
Relevé le 2026-08-20. Plusieurs PDF ont été rafraîchis les 17–18 août 2026 (re-upload FFG).

**Usage projet** : pour builder un scénario de campagne, ouvrir le *Campaign Guide* de la
campagne, lire UNIQUEMENT la section « Setup » du scénario + rendre la page « Suggested
Location Placement » en image. Ne pas lire les résolutions ni interludes (spoilers).
